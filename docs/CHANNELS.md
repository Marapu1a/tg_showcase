# Подключение канала

Реализовано 28 октября 2026 года. Один продавец подключает один канал; один канал принадлежит одному продавцу внутри сервиса. Замена и отключение пока не входят в интерфейс.

## Сценарий

1. Открыть личный чат с ботом, отправить `/start` и нажать «Начать продавать».
2. В приложении нажать «Подключить канал через Telegram» и выбрать канал, согласившись выдать боту право публикации.
3. Сервер проверяет, что это канал, бот — администратор с правом публикации, а продавец — владелец или администратор с правом публикации.
4. Название канала и подтверждение появляются в приложении. При повторном входе подключение загружается из БД.

Основной путь использует [requestChat](https://core.telegram.org/bots/webapps#initializing-mini-apps) и [savePreparedKeyboardButton](https://core.telegram.org/bots/api#savepreparedkeyboardbutton). Нужен клиент Telegram с поддержкой WebApp 9.6. Для старых клиентов есть форма публичной ссылки `https://t.me/name` или `@name`; сначала нужно вручную добавить бота администратором. Пригласительные ссылки закрытых каналов не принимаются — для них нужен штатный выбор канала.

## Данные и доступ

Таблица `SellerChannel`: уникальные `ownerUserId` и `channelId`, название, необязательное публичное имя, дата проверки. Миграция добавляет таблицу без изменения существующих товаров и публикаций. Старый `DEFAULT_PUBLISH_CHANNEL_ID` больше не выбирает канал публикации. Прежние записи офферов сохраняются.

Приватные маршруты требуют Telegram-вход:

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/channels` | Сохранённый канал текущего продавца или null |
| GET | `/channels/bot` | Публичное имя бота для инструкции |
| POST | `/channels` | Проверить и подключить `{ channel: "@name" }` |
| POST | `/channels/verify` | Повторно проверить права |
| POST | `/channels/request-button` | Подготовить штатный выбор канала для текущего пользователя |

Telegram передаёт выбранный канал боту через `chat_shared`. Бот пересылает ID канала и отправителя в `/internal/channel-selection`. Этот маршрут требует отдельный серверный ключ, полученный HMAC из общего токена бота и метки `tg-showcase/channel-handoff`; ключ не попадает в мини-приложение и скрыт в логах. Backend и бот должны использовать токен одного бота. `BACKEND_INTERNAL_URL` в окружении бота указывает на backend; локальное значение — `http://127.0.0.1:3000`. На удалённых хостах использовать защищённое внутреннее соединение или HTTPS.

Даже для доверенного сообщения бота права проверяются через Telegram API. Привязка создаётся только после проверки. Уникальные ограничения БД защищают от одновременного подключения двух каналов или захвата уже подключённого канала. Повтор подключения того же канала допустим.

## Публикация

Перед каждой отправкой backend загружает канал продавца и заново проверяет права через `getChat` и `getChatMember`. При недоступности Telegram, удалённом боте или отозванных правах отправки нет. Ручные `channelId`, `telegramMessageId` и `publishedAt` в создании и изменении оффера отклоняются. Действующий канал берётся только из сохранённой привязки.

Подключение само по себе не публикует посты. Бот отвечает пользователю в личном чате результатом обработки выбранного канала. Общая защита от двойной публикации при одновременных запросах остаётся задачей следующего пакета.

## Проверки и ограничения

- Сборка, линтер, автоматические тесты доступа и подключения.
- Проверяются отсутствие прав, неподходящий тип чата, повторное и конкурирующее подключение, недоступность Telegram, чужая привязка, закрытый служебный маршрут и проверка прав непосредственно перед отправкой.
- Автотесты подменяют Telegram и Prisma; отдельно проверено создание/чтение в локальной PostgreSQL внутри откатываемой транзакции.
- Экраны проверены в браузере на ширинах 390 и 1280 px с подменой API. Это не проверка реального выбора канала в Telegram.
- На 28 октября бот отвечает `getMe`, локальная миграция применена, интерфейс и API доступны через HTTPS-туннели. Сквозной Telegram-вход и выбор настоящего канала требуют проверки владельцем аккаунта. Факт подключения не заявляется до этой проверки.
